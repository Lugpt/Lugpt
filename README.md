## 🚀 正在做的事

**玉衡计划（Astraea Plan）** —— 面向连锁多门店场景的企业级智能体部署架构，一套私有化 AI 全域自治管理系统。

```text
企业 AI 智能体集群 · 生产落地 · 188 家门店
```

- 🏢 已落地 **魔方小镇城市书房** 全国连锁体系（188 家门店 / 20 省 / 50 城市）
- 🤖 14+ 部门智能体（财务/运营/图书/市场/法务/人事/工程…）协同办公
- 🔄 每日自动化闭环：数据汇总 → 工作总结 → 智能复盘 → 管理层汇报
- 🌐 Agent Network：基于 Linux 基金会 A2A 标准协议的智能体间互联（已投入生产）
- 🧠 本地私有化大模型 + 云端大模型双通道灵活选择
- 📚 工作经验沉淀技能体系：人走业务不断，新人快速入岗

## 🛠️ 技术栈

| 领域 | 技术 |
|:--|:--|
| 智能体框架 | Hermes / A2A 协议 |
| 编排调度 | 主控智能体集群 · 星型拓扑 · 部门垂直隔离 |
| 向量检索 | Qdrant + RAG 企业知识库 |
| 模型 | 本地私有化大模型 + 云端大模型双通道 |
| 数据 | PostgreSQL · 银豹 POS 数据管道 · 自动化报表 |
| 前端 | HTML/CSS/JS · 数据看板 |
